## How to read these tables

- **Task:** 5-shot, *N*-way episodic few-shot classification (N = #classes per
  dataset). Nearest-class-mean on frozen features: a class mean is the average
  of its 5 support features, and each query goes to the nearest class mean.
- **Metrics** are mean ± 95% CI over episodes, in **percent**:
  - **OA** — Overall Accuracy. **AA** — Average (per-class) Accuracy.
    **Kappa** — Cohen's kappa.
  - Query sets are class-balanced, so **OA == AA** in every run here (both kept in
    the JSON for completeness; tables show OA and Kappa).
- **Regime** = the *pretraining* masking strategy the encoder was trained with
  (not an eval-time switch): SimMIM masked modelling (band / token /
  band+token), MAE, or a HyperSIGMA adaptation mode.
- **Modality** — `HSI+LiDAR` uses the auxiliary LiDAR/elevation channels;
  `HSI-only` drops them. HyperSIGMA adapts the HSI stream only.
- **Eval protocol** — CoFFE: `k_query=100`, 1000 episodes, Euclidean NCM.
  HyperSIGMA: `k_query=30` (Houston) / 100 (Trento), 600–2000 episodes, **both**
  cosine and euclidean reported.

## Cross-model summary — best configuration per dataset

| Dataset | Best config | OA | Kappa |
|---|---|---:|---:|
| Houston (15-way) | CoFFE · MAE · HSI+LiDAR | **72.15 ± 0.16** | 70.16 ± 0.18 |
| Trento (6-way) | CoFFE · SimMIM token · HSI+LiDAR | **94.19 ± 0.10** | 93.03 ± 0.12 |
| MUUFL (11-way) | CoFFE · SimMIM token · HSI+LiDAR | **67.83 ± 0.17** | 64.61 ± 0.19 |

Headline takeaways:
- **LiDAR helps consistently.** Adding the auxiliary elevation channel lifts OA on
  every dataset (e.g. Houston MAE 69.0 → 72.1; MUUFL SimMIM-token 57.8 → 67.8).
- **Spatial cues dominate.** SimMIM token / band+token regimes and the spatial-pooled
  HyperSIGMA branch beat spectral-only by a wide margin; HyperSIGMA `spectral_only`
  collapses (Houston 15–22% OA), while `spatial_only` ≈ `joint_sem`.
- **HyperSIGMA is competitive on Trento** (joint_sem 86.9 euclidean, within ~7 pts of
  the best CoFFE) but trails the in-domain CoFFE encoder on Houston.
- For HyperSIGMA, **euclidean class means consistently beat cosine** on these features.
